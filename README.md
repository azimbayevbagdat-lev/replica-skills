# Replica skills (3 in 1)

Үш Claude скиллі: кез келген қолданбаның функционалын зерттеп, өз нұсқаңызды жасап, тестілеп, жаңа брендпен шығару.

| Скилл | Не істейді |
| --- | --- |
| `replica-plan` | Қолданбаны зерттеу (экрандар, flow, деректер моделі), стек пен база жоспары, дизайн токендері |
| `replica-build` | Экрандарды жасау, auth/база/төлем/email, тестілеу, түпнұсқамен салыстыру |
| `replica-launch` | Пікірлерден әлсіз жерлерді табу, ребрендинг, лендинг/баға/store мәтіні, деплой |

Ереже: қолданбаның **не істейтінін** қайта жасайды, оның кодын, логотипін, мәтінін немесе контентін көшірмейді.

## Орнату
- **Claude Code**: папкаларды `~/.claude/skills/` ішіне көшіріңіз.
- **Claude (claude.ai / desktop)**: Settings → Customize → Skills арқылы SKILL.md жүктеңіз.
